# Expense Tracker DevOps

A hands-on DevOps engineering project focused on taking a Node.js application from local development to a production-ready deployment using modern DevOps practices.

## Project Goals

This repository documents my journey of building a complete DevOps workflow around an existing application instead of learning tools in isolation.

The goal is to understand **how production systems are built, deployed, monitored, and maintained**.

## Technology Stack

### Application

* Node.js
* MongoDB

### DevOps

* Docker
* Docker Compose
* Jenkins
* Terraform
* Kubernetes
* Prometheus
* Grafana
* AWS

## Repository Structure

```text
expense-tracker-devops/
├── app/                 # Application source code
├── docker/              # Dockerfiles and Docker configuration
├── docker-compose/      # Multi-container application setup
├── terraform/           # Infrastructure as Code
├── kubernetes/          # Kubernetes manifests
├── jenkins/             # CI/CD pipelines
├── monitoring/          # Monitoring configuration
├── scripts/             # Automation scripts
├── docs/                # Project documentation
└── README.md
```
