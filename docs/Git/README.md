# Git Documentation

## Overview

This section contains practical Git commands, workflows, and troubleshooting notes gathered throughout this DevOps mentorship.

The goal is not to document every Git feature, but to build a personal Git reference based on real-world scenarios encountered while working on this project.

---

## Contents

### common-workflows.md

Quick reference for the Git commands used regularly during development.

Topics include:

* Checking repository status
* Staging changes
* Creating commits
* Amending commits
* Pushing changes
* Pulling updates
* Viewing commit history

---

### troubleshooting.md

A collection of Git issues encountered during the project and how they were resolved.

Examples include:

* Non-fast-forward push rejection
* Force push with `--force-with-lease`
* Merge conflicts
* Detached HEAD state
* Authentication issues

(New scenarios will be added as they are encountered.)

---

## Documentation Philosophy

* Document only what has been used.
* Keep explanations concise and practical.
* Record the cause and resolution of real issues.
* Update this section as new Git workflows are learned.
